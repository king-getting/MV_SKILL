# 镜头语言词表与提示词模板

给第 6 步用。目标不是写出漂亮的描述，而是让 50 个镜头看起来像同一部片子。

## style_block 模板

一段话，四件事：材质 / 光学 / 光 / 调色。写死在 bible 里，每个 prompt 原样复制。

```
[材质] 35mm 胶片颗粒，轻微眩光
[光学] 浅景深，50mm 定焦，边缘柔化
[光] 单一主光源，硬光侧逆，暗部保留细节
[调色] 青橙对撞，低饱和，高光偏暖
```

英文模型更吃英文词，但中文模型对中文术语同样敏感。**一套片子里只用一种语言写 style_block**，混写会漂移。

## 景别（size）

| 术语 | 画面 | 适合 |
|---|---|---|
| 大远景 / establishing | 人极小，环境为主 | 段首、副歌第一拍 |
| 全景 / wide | 全身 | 舞蹈、走位 |
| 中景 / medium | 腰以上 | 叙事主体 |
| 中近景 / medium close | 胸以上 | 副歌情绪 |
| 特写 / close | 脸 | 歌词重音、hook |
| 大特写 / extreme close | 眼睛、手、嘴唇 | 打击点、转场 |
| 空镜 / insert | 无主体 | 间奏、呼吸 |

## 运镜（camera）

推（push in，情绪收紧）/ 拉（pull out，揭示）/ 摇（pan）/ 移（tracking）/ 升降（crane）/ 手持（handheld，不安）/ 斯坦尼康（steadicam，流畅）/ 固定（static，克制）。

一条经验：**情绪上升用推，叙事交代用移，转折用固定**。四个镜头里出现三种运镜就会显得乱。

## 转场（transition_out）

硬切（cut）/ 叠化（dissolve，段落之间）/ 白闪（flash，打击点）/ 黑场（fade to black，全曲结束）/ 遮挡转场（whip / match cut，副歌加速）。

默认全部硬切，只在段落边界用叠化。转场花哨是最容易露怯的地方。

## 段落 → 视觉策略

| 段落 | 景别 | 运镜 | 剪辑 |
|---|---|---|---|
| intro | 大远景、空镜 | 固定或极慢推 | 长镜 |
| verse | 中景为主 | 移、跟 | 2 小节一切 |
| prechorus | 中近景，逐镜收紧 | 推 | 1 小节一切 |
| chorus | 特写 + 全景交替 | 推、手持 | 2 小节，末段 1 小节 |
| bridge | 空镜、大特写 | 固定 | 长镜，突然静 |
| outro | 拉远、渐黑 | 拉 | 最后一镜留 3s 以上 |

## 负面词（negative）

通用：`文字, 字幕, 水印, logo, 多余手指, 多余肢体, 脸部扭曲, 低分辨率, 过曝, 塑料感`
人像加：`双胞胎, 镜像重影, 不对称眼睛`
中文歌词 MV 特别注意：生成模型常自己"写"出歌词文字，务必把 `文字, 字幕` 放进负面词。

## 三个反例

| 错误写法 | 问题 | 改法 |
|---|---|---|
| "一个人在雨中回忆失去的爱情，情绪悲伤" | 无主体、无动作、无景别，生成结果不可控 | "中近景，char_01 站在屋檐下，伸手接雨，眼神向下" |
| "把'我就一直跑到天亮'这句歌词画出来" | 一镜多念，模型会塞进跑道+日出+人物+文字 | 拆成两镜：跑道脚部特写 → 日出全景 |
| 每镜重新描述一遍画风 | 50 个镜头 50 种画风 | style_block 固定，只写本镜差异 |

## 一致性检查（填完做一遍）

1. 每个 prompt 是否都以 style_block 原文开头？
2. `subject` 是否都来自 bible？有没有临时造的角色？
3. 同一角色是否都用同一组 `refs`？
4. 副歌二遍（`repeat_of`）是否换了机位/时间/色温，而不是复制？
5. 有没有连续 3 个镜头同一景别？有就换一个。
